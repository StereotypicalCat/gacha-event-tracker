How to Redeem Wuthering Waves Codes

Use the Redeem Function Found in the Game Settings

  1. Open the settings and go to "Other Settings"
  2. Use the "Redemption Code" feature
  3. Enter your redeem code and confirm
  4. Open your mailbox to claim the rewards

Go to Wuthering Waves' "Other Settings", type in your active redeem code, and confirm. A pop-up will appear to let you know if your code was claimed successfully. The rewards will then be sent over to your in-game mailbox.

Claim the Code Rewards Immediately


The mail containing the redeem code rewards will automatically be deleted after two weeks, so you should claim the goods as soon as you can!

Wuthering Waves Code Redeem Site

Wuthering Waves Has No Redeem Site

Wuthering Waves has not implemented a redeem site for you to enter your codes. You can only redeem codes in-game by heading to "Other Settings" and using the Redemption Code feature there.

We will be updating this section if Kuro Games decides to add a Redeem Code feature in their website, so stay tuned!
